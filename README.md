# 🌌 Neon Pulse Runner

A futuristic neon-style endless runner game developed using HTML5 Canvas and JavaScript.

The player must avoid obstacles, collect energy orbs, and survive as long as possible while the game speed gradually increases.

---

## 🎮 Features

- ⚡ Dash mechanic with cooldown bar
- 🪂 Double jump system
- 🛡 Shield power-up orb
- 🎨 Dynamic color themes based on score
- 💥 Camera shake effects
- ✨ Particle and glow effects
- ⏸ Pause system
- 🏆 Persistent high score using localStorage
- 🌠 Animated star background
- 📈 Increasing difficulty over time

---

## 🕹 Controls

| Key | Action |
|-----|--------|
| SPACE | Jump / Double Jump |
| SHIFT | Dash |
| P | Pause / Resume |
| R | Restart |

## Setup and Execution

Clone the repository:

```bash
git clone https://github.com/gulcinyzglc/Neon-Pulse-Runner.git
```

Navigate to the project directory:

```bash
cd Neon-Pulse-Runner
```

Launch the project using a local development server  
(recommended: VS Code Live Server extension).

Alternatively, open `index.html` directly in a modern web browser.

## Requirements

- Modern web browser (Chrome, Edge, Firefox, etc.)
- No external dependencies or installation required

---

## 🎯 Gameplay

- Avoid neon obstacles
- Collect yellow orbs for score
- Collect green orbs for temporary shield protection
- Use dash strategically to destroy obstacles
- Survive as long as possible and beat your high score
